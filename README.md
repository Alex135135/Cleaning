# Чисто — студия химчистки мебели

Исходный проект сайта на React, Next.js, Redux Toolkit и TypeScript.

## Запуск в VS Code

1. Установите Node.js 22.13 или новее.
2. Распакуйте архив и откройте папку `Чисто_проект_VSCode` в VS Code (File → Open Folder).
3. Откройте терминал VS Code (Terminal → New Terminal).
4. Выполните `npm install`.
5. Выполните `npm run dev`.
6. Откройте `http://localhost:3000`.

Для проверки типизации: `npm run typecheck`. Для сборки: `npm run build`. После сборки: `npm start`.

## Структура проекта

- `app/page.tsx` — сборка главной страницы из компонентов.
- `components/layout/` — шапка и подвал.
- `components/sections/` — первый экран, услуги, преимущества, этапы и FAQ.
- `components/calculator/` — калькулятор, строка мебели и форма заявки.
- `components/ui/Logo.tsx` — общий логотип.
- `components/StoreProvider.tsx` — отдельный Redux store для экземпляра приложения.
- `store/` — Redux slice, типизированные хуки и селекторы расчёта.
- `data/services.ts` — услуги и цены; `data/questions.ts` — вопросы и ответы.
- `types/service.ts` — общие типы мебели и услуг.
- `hooks/useQuoteTool.ts` — необязательная браузерная интеграция калькулятора.
- `app/globals.css` — оформление и адаптивные стили.
- `app/layout.tsx` — заголовок и описание сайта.
- `public/` — фотография первого экрана и favicon.

Статические секции остаются серверными компонентами Next.js. Клиентские компоненты используются для FAQ и интерактивного калькулятора. Чтобы изменить цену, достаточно отредактировать `data/services.ts`: новое значение применяется и к карточкам, и к расчёту.

Это демонстрационный сайт. Цены условные. Кнопка «Подготовить заявку» создаёт черновик на странице и не отправляет данные. Для реальных заявок потребуется подключить серверный обработчик или CRM.
